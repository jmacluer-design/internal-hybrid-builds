# Media and sharing

## Share the resource, credit the projects

Use the repo URL until Pages has actually deployed. Link to creator demos, source and releases. Invite missing projects and corrections, not stars. Do not mass-post identical messages or use project bug trackers for promotion.

Suggested launch copy:

> Games inside other games, with the actual source links. Awesome Game Mashups separates playable releases, build-it-yourself code, creator demos and unconfirmed sightings. Search by game, watch the original demos, and submit anything we've missed.
>
> https://github.com/bailo167/awesome-game-mashups

The generated [weekly digest](weekly-digest.md) is a starting point for a brief update in the existing community thread. “Added this week” means added to the catalogue, not necessarily a new game release. Review the digest before posting.

## Original directory walkthrough

A short walkthrough can show the catalogue, filters, project details and source links. Label it as a directory walkthrough, not gameplay. Use the site's original layout without borrowing creator clips. Do not claim every entry is a verified or downloadable game.

Suggested 30-second sequence: title and purpose (5s), featured examples with availability labels (7s), search and demo filter (8s), project details and creator credit (5s), repo address and submission invitation (5s). No fake gameplay or assumed music rights.

## Gameplay montage: obtain permission first

A code licence does not necessarily cover game footage, art or music. A creator link is not permission to download, cut and re-upload their video. Ask for a clean clip and record permission for the platforms and edits involved. Credit each creator on-screen; keep Released / Code only / WIP visible.

Permission request:

> Hey — your project is in Awesome Game Mashups. I'm making a short showcase of the directory. Would you be happy for me to use 5–8 seconds of your gameplay clip in an Instagram/YouTube/Discord post, with your name and project credited on-screen and a link back? Please send the clip you'd prefer and any attribution or editing conditions. No worries if you'd rather I just link to your original video.

Do not publish a montage until rights for every clip and music track are established. Do not use AI-generated gameplay as evidence.

## Social preview

Use an original 1280×640 PNG under 1MB for the repository social preview. The owner uploads it through Settings → General → Social preview. Updating a repository image file does not itself configure that setting.
